
# ETC5523 Blog Assessment

## About the blog
**Data in Perspective** is a data storytelling blog created for ETC5523 - Communicating with Data at Monash University.

The blog post, *What Can Sensors Tell Us About Nitrate in Freshwater Streams?*, explores how high-frequency water-quality sensor data can help us understand nitrate patterns across three freshwater streams in the United States, based on the study by Kermorvant et al. (2023).

The blog highlights how the importance of different environmental factors varies between streams and why local conditions matter for freshwater monitoring.
